    Custom robot grippers for this tool

    Two saddles shaped to the tool's handles. Tape one inside each SO-101 jaw near the tip, set the gripper to the jaw gap below, and zip-tie each handle in through the notches (through the finger loop on scissors). The gripper's own close and open now close and open the tool.

    Gripper pads

    Stick them on the SO-101's jaws. It then holds this object by its own shape.

    Robot fixture

    Holds the part where a robot expects it. Stick the printed tag in the recess; the arm's camera finds it and the pick is in fixture.json. For pick and place, print it twice and use the PDF's second tag in the other.
